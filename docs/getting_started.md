# Getting Started

There are two primary ways to use GraySpace: import the GraySpace appliance to your own infrastructure, or build it on Proxmox VE using the provided tools.

## Gray Space Appliance

The GraySpace Appliance is a virtual machine with Proxmox VE and the tools GraySpace uses. It is being reworked to run the GraySpace container; until then, run GraySpace from a container ([Self-Install](install.md)).

[Get started with the Gray Space Appliance](appliance.md)

## Self-Install

To setup GraySpace on your own infrastructure, see the [installation guide](install.md). Once your environment is prepared, the [Taskfile quickstart](install.md#quickstart-with-taskfile) wraps the whole deploy into a few commands.
